
# Python Wordle

A beginner Python project inspired by the Wordle game.

## What it does

This program takes a guessed word and compares it with a required word.

It checks:

- Whether the guess is an exact match
- Whether a letter is present but in the wrong position
- Whether a letter is in the correct position

## Concepts used

- Functions
- User input
- Strings
- String methods
- `if` statements
- `for` loops
- `range()`
- String indexing
- `return`

## How to run

Run the `Wordle.py` file and enter your guess when prompted.
